

\# Sales Data Analysis Project



\## Project Overview

This project analyzes sample sales data using Python and SQL to identify revenue trends and product performance.



\## Objectives

\- Calculate total sales revenue.

\- Compare revenue across products.

\- Analyze monthly revenue.

\- Practice data analysis and version control.



\## Tools Used

\- Python

\- SQL

\- Git and GitHub

\- CSV



\## Dataset

The dataset is stored in `data/sales.csv` and contains:

\- Order ID

\- Order date

\- Product

\- Category

\- Quantity

\- Unit price



\## Revenue Calculation

Revenue = Quantity × Unit Price



\## Project Structure

\- `data/sales.csv` — sample sales dataset

\- `notebooks/sales\_analysis.py` — Python analysis script

\- `analysis.sql` — SQL analysis queries

\- `README.md` — project documentation

\- `.gitignore` — files Git should ignore



\## How to Run

From the project root directory, run:



```bash

python notebooks/sales\_analysis.py

```
